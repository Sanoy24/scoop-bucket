# Scoop bucket for YTGrab

```powershell
scoop bucket add sanoy24 https://github.com/Sanoy24/scoop-bucket
scoop install sanoy24/ytgrab
ytgrab --open
```

Scoop also installs FFmpeg and Deno, and adds YTGrab to the Start menu. Upgrade with `scoop update ytgrab`.

The manifest is updated automatically from [YTGrab releases](https://github.com/Sanoy24/ytgrab/releases). Report problems in the [main repository](https://github.com/Sanoy24/ytgrab/issues).
